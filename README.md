# Lost & Found System

A web-based Lost & Found system designed for university environments, allowing students to report lost items and browse reported items in a structured and reliable way.

The system follows a full-stack architecture with a REST API backend and a modern frontend interface.

## Project Status
> 🚧 This project is currently under active development.  
> New features, improvements, and refinements are being added incrementally.


## Current Features
- Report a lost item
- View all reported lost items
- RESTful API structure
- Database integration with Supabase

## Tech Stack
- **Frontend:** Next.js (React)
- **Backend:** NestJS
- **Database:** Supabase (PostgreSQL)
- **API Style:** REST
